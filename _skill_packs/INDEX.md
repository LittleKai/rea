# Dormant Skill Packs Index (`_skill_packs/`)

Thư mục này lưu trữ các **gói chuyên môn ngủ đông (`PLAYBOOK.md` + analyzers thuần Python stdlib)** được điều phối qua đúng **1 skill mặt tiền duy nhất** [`.agents/skills/anti-rea/SKILL.md`](../.agents/skills/anti-rea/SKILL.md) (đồng bộ sang `.claude/skills/anti-rea/SKILL.md`).

> **Quy tắc bất biến chống phình ngữ cảnh (`Zero-Context-Inflation`):**
> Tuyệt đối **KHÔNG** đặt bất kỳ file nào tên `SKILL.md` bên trong `_skill_packs/**`. Mọi tài liệu hướng dẫn gói con đặt tên `PLAYBOOK.md` và chỉ được nạp theo nhu cầu thực tế của mục tiêu đang kiểm toán. Khi thêm gói Anti-REA mới trong tương lai, chỉ thêm thư mục con dưới `_skill_packs/anti_rea/<pack-slug>/` và đăng ký vào [`anti_rea/pack_registry.json`](anti_rea/pack_registry.json).
